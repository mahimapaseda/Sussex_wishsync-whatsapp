# WishSync v1.2.2 - Simplified Client Settings & Streamlined Updates

Release **v1.2.2** refines the user interface of the settings modal for end users across all Sussex College branches.

### 🎨 What's Changed

- **Simplified Settings Interface:**
  - Hidden the technical GitHub Personal Access Token field from the Settings view, giving client PCs an uncluttered and straightforward UI.
  - Software Updates now operates seamlessly in token-free mode using direct public release distribution.
  - Preserved the underlying token handling architecture for private enterprise configurations if needed.
